# 元祖塩ホルモン大豊

静的 HTML / CSS のサイト制作案です。店名・住所・営業時間・定休日は提供された店舗情報を掲載しています。提供された店内写真からメニューの一部と税込価格、電話番号を掲載しています。ロゴは assets/taiho-logo.jpg に原画像のまま保存し、サイト上部のヘッダーとフッターに使用しています。元のメニュー写真は未保存です。

## ローカル起動

```sh
cd /workspace/taiho
python3 -m http.server 8000 --bind 127.0.0.1
```

`index.html` に内容、`style.css` にデザインを記載しています。ビルドや追加依存関係は不要です。Google Fonts が利用できない場合はシステムのセリフ体で表示します。
