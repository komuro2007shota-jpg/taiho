# 元祖塩ホルモン大豊

静的 HTML / CSS のサイト制作案です。店名・住所・営業時間・定休日は提供された店舗情報を掲載しています。提供された店内写真からメニューの一部と税込価格、電話番号を掲載しています。ロゴは assets/taiho-logo.jpg に原画像のまま保存し、サイト上部のヘッダーとフッターに使用しています。元のメニュー写真は未保存です。

## ローカル起動

```sh
cd /workspace/taiho
python3 -m http.server 8000 --bind 127.0.0.1
```

`index.html` に内容、`style.css` にデザインを記載しています。ビルドや追加依存関係は不要です。Google Fonts が利用できない場合はシステムのセリフ体で表示します。

## ニュースの更新

GitHub で `news.js` を開き、鉛筆アイコンから編集します。`window.TAIHO_NEWS = [` と `];` の間に、次の形式で投稿を追加して Commit changes で保存してください。

```js
{ date: "2026-10-12", title: "お知らせのタイトル", body: "本文の1行目\n本文の2行目" },
```

日付は `YYYY-MM-DD`、タイトルと本文は引用符で囲み、投稿の末尾にカンマを付けます。新しい日付順に自動表示します。削除はその投稿を取り除きます。最初の記事として2026年10月12日付の公式ホームページ開設のお知らせを掲載しています。GitHub Pages が有効な場合、保存後のデプロイ完了でサイトへ反映されます。予約投稿機能はなく、登録した投稿はすべて表示されます。

確認用HTMLとバックアップの再生成：`python3 scripts/preview.py`。ブラウザ用サーバーは引き続き README の起動手順を使用します。
